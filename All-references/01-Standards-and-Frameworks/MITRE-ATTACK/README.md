# MITRE ATT&CK

## Source
- **Name:** MITRE ATT&CK
- **Publisher:** MITRE
- **Official website:** https://attack.mitre.org/
- **Enterprise introduction:** https://attack.mitre.org/resources/enterprise-introduction/
- **Working with ATT&CK:** https://attack.mitre.org/resources/working-with-attack/

## What it provides
MITRE ATT&CK is a knowledge base of adversary tactics and techniques based on observed behaviour. It provides a common vocabulary for describing adversary activity and mapping detections, investigations, and defensive measures.

## Relevance to this project
ATT&CK can support:
- describing observed attacker behaviour during incident triage;
- mapping evidence and alerts to tactics and techniques;
- contextualising threat intelligence;
- connecting incident findings to response playbooks;
- communicating the threat scenario used when evaluating response and recovery.

## Important boundary
ATT&CK is not, by itself, a recovery-point integrity standard, a backup trust score, or an authorisation mechanism. Any Recovery Trust Score and recovery policy gate proposed by this project must be separately defined, justified, and evaluated.

## Versioning and citation
ATT&CK is maintained online and changes over time. When using it:
1. Record the access date.
2. Record the ATT&CK version if a version-specific dataset or release is used.
3. Cite the official MITRE resource.
4. Identify the exact tactic, technique, or data source used rather than citing the framework generically.
