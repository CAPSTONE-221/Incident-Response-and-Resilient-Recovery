# CIC-IDS-2017 Network Intrusion Detection Dataset

## Overview
CIC-IDS-2017 is a benchmark network intrusion detection dataset generated by the Canadian Institute for Cybersecurity (UNB). It contains realistic background traffic generated using the B-Profile system combined with modern simulated cyberattacks executed over 5 days.

- **Source**: University of New Brunswick (UNB)
- **URL**: https://www.unb.ca/cic/datasets/ids-2017.html
- **Format**: CSV (CICFlowMeter 80+ flow features) and Raw PCAP
- **Total Records**: ~2.83 million flows
- **Size**: ~1.5 GB CSV / ~50 GB PCAP

## Attack Distribution by Day
- **Monday**: Benign activity only (baseline profile)
- **Tuesday**: FTP-Patator, SSH-Patator (Brute Force)
- **Wednesday**: DoS (Slowloris, Slowhttptest, Hulk, GoldenEye), Heartbleed
- **Thursday**: Web Attacks (Brute Force, XSS, SQL Injection), Infiltration
- **Friday**: Botnet (ARES), PortScan, DDoS (LOIC)

## Target Role in Framework
1. **Triage Agent**: Multi-class classification model training (Normal vs. Specific Attack Type) to assign initial incident priority and severity.
2. **Investigation Agent**: Flow timing metrics (IAT, packet inter-arrival) for detecting burst exfiltration or C2 beaconing.
