# OTRF Security Datasets (Mordor)

## Overview
Managed by the Open Threat Research Forge (OTRF), this repository contains pre-recorded security event logs generated by executing real adversary techniques in controlled lab environments. Every dataset is mapped to specific MITRE ATT&CK tactics, techniques, and procedures (TTPs).

- **Source**: Open Threat Research Forge (Roberto Rodriguez / Jose Luis Rodriguez)
- **Repository**: https://github.com/OTRF/Security-Datasets
- **Companion**: https://threathunterplaybook.com/
- **Format**: JSON / JSON-lines (Windows Event Logs, Sysmon, Zeek)
- **Coverage**: Enterprise ATT&CK matrix techniques

## Content Structure
- Organized by ATT&CK Tactics:
  - Initial Access, Execution, Persistence, Privilege Escalation, Defense Evasion, Credential Access, Discovery, Lateral Movement, Collection, Exfiltration, Impact.
- Contains pre-packaged attack simulations (Atomic tests, Empire, Cobalt Strike, Metasploit captures).

## Project Role: Automated Ground-Truth Validation
- **Validation Agent**: Serves as ground-truth telemetry to test whether the agentic framework detects and blocks specific adversary procedures.
- **Triage & Investigation Models**: Fine-tuning LLM chain-of-thought prompts on structured Sysmon JSON logs corresponding to known attack techniques.
